# Readly (Android) — офлайновая читалка в духе ReadEra

Полноценный Gradle-проект Android Studio: открывается и собирается «как есть»
на актуальных версиях Android Studio и Gradle. UI — целиком **Jetpack Compose**
(Material 3), исходники — в «плоском одном пакете» `com.example.readly`,
векторные иконки — в `res/drawable` (`R.drawable.ic_*`), строковые литералы
русские.

## Возможности

- **Библиотека** — сетка обложек, бургер-меню справа: фильтры «Все / Читаю /
  Не начатые / Прочитанные» (при входе открывается «Читаю»), страницы
  «Авторы» и «Корзина», «Добавить книги», папки автозагрузки, изумрудная
  тема; сортировка, поиск, долгое нажатие на книгу — читать /
  редактировать название и автора / отметить прочитанной / сбросить
  прогресс / удалить.
- **Доступ только к выбранному (SAF)** — разрешений на память нет:
  книги добавляются выбранными файлами или папками в системном окне.
  Выбранные папки (можно несколько) запоминаются, сканируются рекурсивно
  и при каждом запуске сами подхватывают новые книги — как ReadEra
  с папкой «Загрузки» (подробно — в разделе 7).
- **Форматы: EPUB / FB2 (.fb2.zip) / DOCX / TXT / MOBI (PRC, AZW, AZW3) /
  RTF** — собственные потоковые парсеры: книга не грузится в память
  целиком, большие файлы (> 26 МБ) открываются без сбоев. Кодировки
  (UTF-8/16, windows-1251) определяются автоматически; формат — по
  содержимому, а не по расширению. «Битые» книги с сайтов-скачивалок
  открываются каскадом фолбэков: подменённый формат, data descriptors
  (WebToEpub), недокачанные архивы, EPUB без container.xml, битый spine,
  записи без расширения — вплоть до прямого извлечения текста из любой
  записи архива. Картинки сохраняются (крупные пережимаются в JPEG).
- **Оглавление** — из TOC/NCX EPUB, заголовков секций FB2, стилей Heading
  DOCX (по каноническому имени стиля — работает с любыми локализованными
  styleId) или по маркерам «Глава N / Пролог / Эпилог…» прямо в тексте —
  для всех форматов, когда своего оглавления нет.
- **Экран чтения** — вертикальная лента, тап-зоны (центр — меню, правый
  верхний угол — закладка), автосохранение позиции, экран не гаснет;
  картинки внутри текста; ссылки: внешние — в браузер, mailto — в почту,
  внутренние (сноски, оглавление) — переход по книге с точностью до абзаца.
- **Вид** — 3 гарнитуры (Санс/Сериф/Моно), размер 12–30 sp, интервал
  1.0–2.0, 4 темы (Светлая / Сепия / Тёмная / Чёрная OLED) — мгновенно.
- **Закладки** — тап в правом верхнем углу ставит/убирает закладку;
  список со сниппетами, переходом, удалением и переименованием.
- **Поиск по тексту книги** — с подсветкой и переходом к совпадениям.
- **Корзина** — удаление перемещает в корзину; восстановить или стереть
  окончательно (опционально вместе с исходным файлом в выбранной папке).

## 1. Требования

| Что | Значение |
|---|---|
| Android Studio | актуальная стабильная (поддержка AGP 9.x) |
| AGP | **9.4.1** (встроенный Kotlin 2.2.10 — плагин `kotlin-android` не нужен) |
| Gradle | **9.8.1** (wrapper включён: `gradlew` + `gradle-wrapper.jar`) |
| JDK | 17+ (в Studio — встроенный JBR 21) |
| compileSdk | 37 (максимум, поддерживаемый AGP 9.4) |
| targetSdk | 35 (edge-to-edge; отступы — через WindowInsets в Compose) |
| minSdk | 23 |

Версии заданы в **`gradle/libs.versions.toml`** (version catalog — стандарт
современных проектов); менять их достаточно в одном месте.

## 2. Сборка

[readly.zip](https://github.com/user-attachments/files/33509142/readly.zip)
> **Про архив:** `readly.zip` распаковывается **в папку `Readly/`** — внутри
> сразу лежат `settings.gradle.kts`, `app/`, `gradle/` и т.д. Открывайте
> в Android Studio именно эту папку (File → Open → `Readly`).

### Android Studio
1. File → Open → выбрать папку проекта (где `settings.gradle.kts`).
2. Дождаться синхронизации Gradle (все зависимости подтянутся сами).
3. Run ▶ — приложение установится и запустится.

### Командная строка
```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug         # + установка на подключённое устройство
./gradlew assembleRelease      # release (минификация выключена)
```

### Если Run не ставит приложение: INSTALL_FAILED_USER_RESTRICTED

«Installation via USB is disabled» — это **не ошибка проекта**: APK собрался,
но телефон запретил установку через USB. Это блокирует сам телефон —
настройки разработчика. Исправляется один раз:

1. **Включите режим разработчика** (если ещё нет): Настройки → «О телефоне» →
   7 раз тапнуть по «Номеру сборки» (на Xiaomi — по «Версии MIUI/HyperOS»).
2. Откройте **Настройки → Расширенные настройки → Для разработчиков** и включите:
   - «Отладка по USB»;
   - **«Установка через USB»** ← именно этот пункт выключен, ошибка про него.
3. Переподключите кабель: в шторке уведомлений выберите режим
   **«Передача файлов»** (не «Только зарядка»), затем подтвердите отпечатком
   запрос «Разрешить отладку по USB».
4. Снова Run ▶. На телефоне в момент установки может появиться диалог —
   **сразу нажмите «Разрешить»** (установщик закрывается по таймауту ~10 с).

Нюансы по брендам:

| Бренд | Что дополнительно требуется |
|---|---|
| Xiaomi / Redmi / Poco | Для «Установки через USB» нужен **вход в Mi-аккаунт и SIM-карта**; после входа подождите 5–10 минут (сервер проверяет аккаунт). Если не помогло — там же отключите «Оптимизацию MIUI» и перезагрузитесь; включите «Отладка по USB (настройки безопасности)» |
| Oppo / Realme / OnePlus | «Установка через USB» активируется после входа в аккаунт производителя (подождите 5–10 минут) |
| Huawei / Honor | Включите «Отладка по USB» и «Разрешить ADB-установку»; режим USB — «Передача файлов» |
| Vivo | «Установка через USB» активируется после входа в аккаунт vivo |
| Samsung | Настройки → Безопасность и конфиденциальность → выключите **«Автоблокировщик» (Auto Blocker)** — он блокирует ADB-установку |

Проверка, что телефон виден системе: `adb devices` в терминале Android
Studio (View → Tool windows → Terminal) должен показать устройство со
статусом `device`.

Версии подобраны согласованно и проверены по метаданным репозиториев:
AGP 9.4.1 несёт встроенный Kotlin **2.2.10**, и ровно та же версия взята для
плагина компилятора Compose (`org.jetbrains.kotlin.plugin.compose:2.2.10`).
Compose BOM **2025.12.01** (ui/foundation 1.10.0, material3 1.4.0) собран
в эпоху Kotlin 2.2.x и совместим со встроенным Kotlin AGP.

## 5. Хранение данных

- `filesDir/library.json` — книги, прогресс, закладки (атомарная запись
  tmp + rename, доступ синхронизирован, подписка через `StateFlow`);
- `filesDir/books/<uuid>.<ext>` — копии файлов книг. **По умолчанию
  книги НЕ копируются** (режим «без копии», как в ReadEra): в запись
  сохраняется SAF-URI исходного файла, а при открытии книга копируется
  во временную копию `cacheDir/books/<uuid>.<ext>` (чистится при
  запуске). Копия в `filesDir/books` создаётся только если системе
  нельзя выдать постоянное разрешение на URI (например, лимит грантов);
- `filesDir/covers/<uuid>.jpg` — уменьшенные (≤512 px) обложки;
- `SharedPreferences("reader_prefs")` — тема, шрифт, размер, интервал;
- `SharedPreferences("library_prefs")` — выбранные папки поиска книг,
  «надгробия» удалённых книг и акцентная тема приложения
  (стандартная/изумрудная).

Благодаря режиму «без копии» размер данных приложения остаётся в
килобайтах — библиотека не дублирует файлы книг (раньше каждая книга
копировалась в приватный каталог, и приложение «весило» гигабайты).
Чтобы освободить место от СТАРЫХ копий: удалите книгу из приложения
и добавьте её заново — новая запись не создаст копию.

Прогресс сохраняется автоматически при уходе с экрана чтения (ON_PAUSE)
и восстанавливается при открытии; доля прочитанного ≥ 99,5 % помечает
книгу как прочитанную.

## 6. Управление в читалке

| Действие | Результат |
|---|---|
| Тап в центре экрана | показать/скрыть меню (системные панели тоже появляются), снять подсветку поиска |
| Тап в правом верхнем углу | поставить/убрать закладку в текущей позиции (как в ReadEra) |
| Тап по абзацу с закладкой | убрать закладку |
| Тап по ссылке в тексте | внешняя http/https — в браузер; mailto — в почтовое приложение; внутренняя (оглавление EPUB, сноски) — переход внутри книги |
| Стрелки в нижней панели | предыдущая/следующая глава |
| «Глава N из M» в нижней панели | открыть оглавление |
| Свайп | обычная вертикальная прокрутка ленты |
| Открытие панели (оглавление/поиск/…) | меню скрывается; назад/тап по фону — закрыть панель |

## 7. Папки автозагрузки и поиск книг на устройстве

Приложение НЕ запрашивает «Доступ ко всем файлам» и вообще не требует
разрешений на память. Доступ выдаётся только к тому, что пользователь
сам выбирает в системном окне (SAF):

| Пункт меню | Что делает | Стартовая папка пикера |
|---|---|---|
| «Добавить книги» | импорт выбранных файлов (можно сразу несколько) | Загрузки |
| «Найти книги на устройстве» | выбор папки для поиска книг | корень накопителя |
| «Выбрать папку автозагрузки» | выбор папки, из которой книги добавляются сами | Загрузки |

> **Телефон не даёт выбрать «Загрузки»** (сообщение «в целях
> конфиденциальности нельзя выбрать эту папку» — HyperOS/ColorOS и
> некоторые другие прошивки запрещают выбирать корни системных папок).
> Это ограничение САМОЙ системы, а не Readly, и действует только на
> выбор ПАПКИ. Пункт «Добавить книги» — обычный пикер ФАЙЛОВ: он
> открывает «Загрузки» без этого запрета (мультивыбор); либо выберите
> любую вложенную папку (например, `Download/Books`) — скан рекурсивный.

Выбранные папки запоминаются (persistable-доступ — переживает
перезагрузку), их может быть несколько. При каждом запуске приложение
рекурсивно обходит все выбранные папки и само добавляет появившиеся
книги (тост «Найдено новых книг: N») — так Readly читает скачанные
файлы, как ReadEra из папки Download.

### Правила

- Берутся файлы: `.epub`, `.fb2`, `.fb2.zip`, `.docx`, `.txt`
  (а также `.text`/`.log`), `.mobi`/`.prc`/`.azw`/`.azw3`, `.rtf`,
  `.html`/`.htm`, `.zip`/`.fb2z`.
- **Дубли исключены**: сверка по паре «имя + размер» — книга не
  добавится дважды, переименованная в библиотеке не тронется.
- **Удалённое не возвращается**: книга, стёртая с устройства из корзины,
  не импортируется снова, даже если файл остался в папке (вернуть можно
  вручную — «Добавить книги»).
- Книги остаются на своих местах (режим «без копии»): доступ даёт
  сохранённое разрешение на выбранную папку.
- Папка, доступ к которой отозван системой, исключается из списка
  автоматически; отказ в отдельном подкаталоге просто пропускает его.
- Скрытые (`.…`) и служебные (Android, DCIM, Music…) папки
  пропускаются; обход ограничен 2000 папок / 50 000 файлов.
- **Сброс**: долгое нажатие на пункт «Выбрано папок автозагрузки»
  забывает все выбранные папки.

### Если что-то не подхватывается

| Симптом | Что делать |
|---|---|
| Новая книга не появляется | Проверьте расширение файла и что папка ещё выбрана; книга не совпадает по имени и размеру с уже добавленной |
| «Доступ к папке потерян» в логах | Папку удалили или доступ отозван — выберите её заново |
| Хочу дополнительную папку | Просто выберите ещё одну — папки суммируются |
| Хочу сбросить автозагрузку | Долгое нажатие на пункт папки в бургер-меню |
| Система не даёт выбрать «Загрузки» | Ограничение прошивки (действует только на выбор папки): берите книги через «Добавить книги» (пикер файлов стартует в «Загрузках») или выберите вложенную папку |

Пример рабочего сценария: скачали три книги в `Download` → открыли
Readly → книги уже в библиотеке, с обложками и оглавлением.
